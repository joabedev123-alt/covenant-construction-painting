COVENANT CONSTRUCTION & PAINTING — IMAGE ASSETS FOLDER
======================================================

You can place your project image files directly in this folder:

1. logo.png                   -> Official brand logo (will automatically replace the default vector logo if present)
2. bathroom-before.jpg        -> Real bathroom photo BEFORE renovation
3. bathroom-after.jpg         -> Real bathroom photo AFTER renovation
4. staircase-transformation.jpg -> Real staircase before & after photo

All image slots are centralized in:
/src/data/assets.ts

Updating or replacing any photo is as simple as dropping the file here or changing the path in /src/data/assets.ts.
